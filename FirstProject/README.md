# Product Catalog Website

This is my first HTML project, created to practice the fundamentals of HTML5 and semantic web development.

## 📌 Features

* Product catalog with three categories:

  * Electronics
  * Clothing
  * Home
* Internal navigation using anchor links
* Product descriptions, prices, and availability
* Expandable product specifications using the `<details>` element
* Images for each product
* Semantic HTML structure

## 🛠️ Technologies Used

* HTML5
